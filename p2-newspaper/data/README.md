# Data

```
data/
  synthetic/        generated by `python -m p2news synth` (git-ignored)
    pages/          page images
    gold/           gold labels, one JSON per page
  real/             your scans (create it)
    pages/
    gold/           from `python -m p2news labelstudio export.json data/real/gold`
  raw/              anything large you don't want in git (git-ignored)
```

## Where to get pages

1. **The trainer's pages**: use these for the review.
2. **Chronicling America** (Library of Congress, https://chroniclingamerica.loc.gov): digitized US newspapers up to 1963, so the 1950s are covered. Page images are JPEG 2000 (`.jp2`), which the pipeline reads. If yours won't open, convert them to PNG first.
3. **American Stories** (https://huggingface.co/datasets/dell-research-harvard/AmericanStories): article-level text and layout extracted from Chronicling America. Useful to compare against; it isn't perfect ground truth. Check the licence before you use it.

## Gold label format

One file per page, named `<page_id>.json`, where `page_id` is the image file name without its extension.

```json
{
  "page_id": "synth-001",
  "width": 2400,
  "height": 3300,
  "language": "en",
  "articles": [
    {"article_id": "synth-001-g001", "bbox": [90, 90, 620, 1450], "text": "Council Approves New Bridge Plan ..."}
  ],
  "lines": [
    {"box": [90, 92, 540, 130], "text": "Council Approves New", "article_id": "synth-001-g001"}
  ]
}
```

- `bbox` and `box` are `[x0, y0, x1, y1]` in pixels of the original image, origin top-left.
- `text` is optional. Without it, CER isn't measured for that article.
- `lines` is optional. Without it, grouping F1 isn't measured and `--gold-lines` can't be used for that page. Hand-labelled real pages normally only have `articles`.
